# blink-app

This is a tiny static webpage that displays a large exclamation mark (`!`) centered on a white background.

## How it works

- `index.html` contains both the markup and CSS.
- The page uses CSS Grid (`place-items: center`) to center the exclamation mark in the viewport.
- A `@keyframes blink` animation toggles the mark's opacity so it blinks forever.

## Run locally

Open `index.html` directly in your browser, or serve this folder with any static file server.
